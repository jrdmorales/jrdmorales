## 👨‍💻 Sobre mí

Soy Analista Programador enfocado en el desarrollo de **software empresarial, automatización de procesos e integración de sistemas**.

Trabajo principalmente con **Python, TypeScript, Next.js y FastAPI**, complementando el desarrollo de aplicaciones con conocimientos de **Docker, Linux, bases de datos, APIs REST, CI/CD e infraestructura**.

Mi enfoque está en construir soluciones mantenibles y escalables, desde el desarrollo de la aplicación hasta su integración, despliegue y operación.

Actualmente estoy profundizando en **arquitectura de software, DevOps y cloud infrastructure**.

### Áreas principales

* **Software Development:** Next.js, React, TypeScript, Python, FastAPI
* **Backend & APIs:** REST APIs, Node.js, FastAPI
* **Databases:** PostgreSQL, SQL Server
* **DevOps & Infrastructure:** Docker, Docker Compose, Linux, Git, CI/CD
* **Automation:** Python, Power Automate, Selenium
